# CoCo 小克克 · AI 产品经理

CoCo 小克克的个人网站，包含个人介绍、产品概念探索和产品思考。

网站地址：https://liyajing-product.github.io/

## 文件说明

- `index.html`：页面结构与文案
- `style.css`：视觉样式、桌面和移动端布局
- `script.js`：项目筛选、详情弹窗和复制个人介绍
- `favicon.svg`：网站图标
- `.nojekyll`：直接发布静态文件

## 本地预览

直接用浏览器打开 `index.html`，或在当前目录运行：

```sh
python3 -m http.server 8080
```

打开 http://localhost:8080/ 。

## 发布与更新

GitHub Pages 使用 `main` 分支的根目录。修改文件并推送到 `main` 后，GitHub 会自动更新网站。

首版中的三个项目均为明确标注的概念示例，产品思考为待 CoCo 确认的文案草稿。正式使用时请替换为真实项目与个人内容。
